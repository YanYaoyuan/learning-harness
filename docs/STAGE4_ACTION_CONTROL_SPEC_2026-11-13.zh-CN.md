# Stage 4：任务与动作构成匹配下的经验选择

日期：2026-11-13。完整Stage 3与固定检查点复测后的后续研究；新训练前固定方案。它沿用已多次检查的64个开发任务，因此属于机制探索，不作为未见测试集上的确认性结论。

## 问题与既有证据

Stage 3完成70模型/4480回合；任务位置、次数、不同内容数和优化预算匹配后，低NLL−随机成功率为API −17.7734pp、generic −7.8125pp，四初始化平均方向一致。原低NLL选择会改变动作构成；需要检验匹配这一因素后仍有多少内容选择差异。原API−ReAct强基线的负向结果继续保留。

独立复测两个已保存检查点共128回合；逐任务成败和步数均与各自原记录一致。相同种子角色、配置和调度的条件重训仍有实际参数差异。这支持增加初始化重复，而不改变训练精度、算法或优化器来混入新因素。

## 控制与干预

- 两来源：旧API与generic成功经验池，不新增教师调用。
- 两策略：在相同任务×动作类型分层内随机选择，或选择基础学生低目标NLL内容。
- 16份真实配方：2来源×2策略×4采样配方。逐位置任务ID、动作类型及分层次数一致；逐层、逐任务及全局不同内容配额一致。每模型256条不同任务内容、768次呈现、192次更新。
- 配额沿用Stage 3随机参考，不补齐参考中不存在的动作类别。因此结论以该参考支持为条件。
- 动作匹配后两策略的不同支持约为API 25.59%、generic 37.30%；NLL选择差异保留原任务匹配的约66.15%与40.44%。干预强度也变弱，不能把效果衰减直接当成动作构成的因果中介比例。
- Qwen3-4B-Instruct-2507模型revision、LoRA、优化器、训练预算、共同JSON执行内核及A+零B组成全部继承父研究，实际token消耗另外报告；次数匹配不声称精确FLOP匹配。

## 重复、预算与固定队列

初始化101/202/303/404/505/606，采样配方101/202/303/404，两来源×两策略，共96个主要模型；另在初始化101/采样101对两来源和两策略各重训一次，共4个条件重复。总100模型、6400新评测回合。

六初始化的选择发生在Stage 4产生任何结果之前，目的是更完整呈现已观察的训练变异，不声称满足某个预设显著性检验力。原四初始化草案另存，模型预算及已有四初始化GPU分配不变；新增两个初始化依原规则交替GPU及策略先后顺序。同一来源/初始化/采样配方的策略对使用同一物理GPU。

两张5090并行，上限18累计GPU小时；每模型最多预留1800秒，剩余未预留预算少于900秒不启动下一模型。失败、超时和中断时间均计入。完整父实验平均约531秒/模型，线性估计本轮约14.8累计GPU小时；这是预算估计，不是墙钟承诺。

启动前检查两GPU、既有模型服务端口、存储容量和明确记录的空闲后台上下文；不停止其他应用。预留项绑定worker PID、GPU、时限与冻结哈希。保持localhost不经过代理。

## 终点与解释

主要终点为每模型无辅助成功率：冷却/加热各32个固定开发任务，两个任务族等权；环境种子11、温度0、batch 8。主要对比是在每来源内计算低NLL−随机，先在24个初始化×采样配对单元等权平均，再逐初始化报告四个采样配方平均。两个来源分列，不当作独立环境。

所有成对单元、六初始化值、胜/平/负、任务族分解和原始成功/失败保留。条件训练重复不进入主均值，另报差值。诊断NLL、实际token及动作/内容配额核对为辅助结果。不给出未经校准的少种子bootstrap区间或显著性结论。

若匹配动作后差异仍存在，支持剩余内容选择效应；若差异缩小或消失，结果约束经验价值代理的适用条件，同时必须报告选择强度变化和训练波动。无论方向如何都完成既定队列、保留强基线，不能以不显著声称等效或证明动作构成是唯一机制。
