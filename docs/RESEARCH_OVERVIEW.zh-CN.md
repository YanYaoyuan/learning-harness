# 研究设计

论文：[From Acting to Learning: Experience Selection toward Continually Learning Agents](https://arxiv.org/abs/2611.27159)。

## 研究问题

成功交互为智能体提供训练材料，但不同成功记录的学习价值并不相同。本研究在固定学生、执行器和训练预算下，比较动作经验的选样规则，并考察任务覆盖约束如何影响结果。

实验使用 Qwen3-4B-Instruct-2507 与 ALFWorld 文本环境。模型接收公开文字观测、输出离散命令；训练采用 LoRA SFT。两个固定经验池分别来自 API 策略辅助和通用提示辅助采集。

## 选样实验

| 条件 | 选样规则 | 覆盖约束 |
|---|---|---|
| 匹配覆盖 | 随机、低/中/高 NLL、梯度高/低分 | 相同任务与动作配额 |
| 全局选择 | 随机、高 NLL、梯度高分 | 各规则共享相同可选空间 |

八个初始化种子与两个采样种子共得到 288 个学生。每个学生使用 256 条不同内容、768 次样本呈现。梯度分数采用 LESS 风格的优化器感知特征和公开目标支持；最终学生从共同基础模型重新初始化。

开发评测包含 128 个任务组。独立冻结的保留面板另含 128 个任务组，复用 97 个检查点完成 12,416 回合。两来源等权的保留集收益为梯度相对随机 +7.03、相对高 NLL +5.03 个百分点。完整成功率见[项目首页](../README.md#results)。

放宽覆盖约束后，梯度选样改善、随机选样下降，说明选样规则与可选空间需要共同评估。现有对照尚不能把差异唯一归因于任务覆盖、动作构成或长度中的某一项。结果适用于本次有限任务面板，未使用官方 seen/unseen 测试集。

## 与早期采集实验的关系

早期工作比较教师辅助采集与 ReAct 自采，在共同成功的任务/采样种子上匹配动作标签，再训练学生并评估无辅助能力及后续适应。该阶段区分了采集成功、训练起点、原始 AUC 和 gain AUC，也暴露出覆盖、样本预算与少训练种子带来的不确定性。

| 早期流程 | 采集 | 训练 | 评测 |
|---|---|---|---|
| 教师辅助 | 根据公开初始观测生成短策略，前四步辅助学生 | 去除提示、示例和思考，使用公开动作视图 SFT | 统一执行器，撤除教师辅助 |
| ReAct 自采 | 同一学生使用固定 ReAct 示例 | 相同动作视图、共同成功匹配与 SFT 预算 | 相同任务和执行方式 |
| 无 A 训练参考 | 基础模型 | 相同后续 B 教学序列 | 相同任务与预算 |

两个采集流程同时改变示例、格式和推理方式，因此其差异属于流程比较。后续选样实验把研究对象收敛到既有经验池，在共同起点和训练预算下比较记录的选择方式。跨轮持续学习、长期保持和在线 agentic RL 尚待单独评测。
