# 研究方案与思路

本项目研究：**提高 agent 当场完成任务的 harness，是否也能产生更有利于小模型学习和后续适应的经验？** 即时成功、撤除辅助后的能力、后续学习收益分别测量。

目前使用 Qwen3-4B 和 ALFWorld 文本环境，在双 RTX 5090 上开展探索；另有 4×A100 40GB 可用资源。当前不是机械臂视觉控制实验，也尚未证明 RSI 或提出已验证的新 SOTA 方法。

## 我们的候选方案与强基线

| 角色 | 采集 | 学习 | 评测 |
|---|---|---|---|
| 候选方案 | 教师仅根据公开 reset 提供短策略，前四步辅助小模型 | 移除提示、示例和思考，公开动作轨迹 SFT | 撤除教师辅助，共同执行方式 |
| 强基线 | 同一小模型用固定 ReAct 示例自行完成任务 | 同样的公开动作视图、任务匹配和 SFT 预算 | 完全相同执行方式 |
| 无 A 训练参考 | 不进行前期经验内化 | 相同后续 B 教学序列 | 相同测试任务与预算 |

候选方案与强基线都重新采集，按共同成功的任务/采样种子配对，逐对匹配动作标签数量；三种训练种子、相同更新次数和样本呈现预算。真实输入/目标 token 另记，不能将等样本数描述为等 FLOPs。

## 为什么这样设计

1. 更好的采集成功率不必然带来更好的训练数据。成功筛选、任务覆盖和轨迹长度都会改变可学习内容。
2. 更高的学习曲线 AUC 可能来自起点更强。因此同时报告初始能力、原始 AUC、gain AUC、终点和任务族分解。
3. 辅助撤掉后仍有收益，才可能涉及参数内化；同任务反思重试不等于参数学习。
4. 旧直接行动基线过弱，必须加入 ReAct 自采→SFT，而不能只展示 ReAct/Reflexion 本身的推理分数。
5. 两个采集流程同时改变了示例、格式和推理机制，当前比较是完整流程比较；若要识别教师卡片的独立作用，还需在相同 actor 上做消融。

## 已有证据与尚未解决的问题

早期辅助采集明显提高成功率；部分任务族有训练起点与迁移收益，但一般学习效率优势尚不稳定。详见[历史审计](EXPERIMENT_AUDIT_2026-11-10.zh-CN.md)，保留正面证据与不确定性，不把不显著结果当成等效或全面失败。

执行基线对照发现，示例和 ReAct 大幅提高了原直接行动的表现。发现并剔除了一个官方示例重合开发任务；[完整结果](../output/baseline-benchmark-v1/RESULTS.zh-CN.md)同时报告 40 题与剔除后的 39 题。这一实验没有更新参数，不能单独证明候选学习方案有效。

正在进行的核心对照见[冻结协议](SOURCE_COMPARISON_V1.zh-CN.md)。两个来源各 144 次采集，6 个新 A adapter，12 条新 B 适应轨迹，另复用 6 条无 A 参考权重但重新评测。冷却与加热分别表示 A 未训练任务族和同族新任务。正式 seen/unseen 仍保留。

## 结果解释边界

- 本轮复用开发查询，属于探索性验证，不冒充新鲜确认性测试。
- 共同成功匹配改变了估计适用的任务范围，不能据此评价全部任务覆盖收益。
- 当前 B 适应是冻结 A、训练新增 B LoRA；不能直接称为同一组参数的纯可塑性。
- ReAct 评测会提供对应任务族示例，属于 few-shot 执行。
- 基础模型预训练污染和 BF16 批处理差异不能被简单假定不存在。
- 任何论文层面的优势主张，都需要强基线比较、适当消融和最终保留集证据。
