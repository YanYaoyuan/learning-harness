# WebShop基础学生校准协议

这一步检验公开提示的chat/native移植及基础学生起点，只使用train，不作正式benchmark或新方法效果的证据。公开来源、原远程观察与本地DOM差异见公开基线来源审计。

## 固定范围与顺序

使用封存的2022 LG原版奖励、完整目录/索引及seed11目标映射。仅全局train编号1500—1531，32目标各运行ReAct `prompt1`和Act-only `prompt1_actonly`，共64回合；相邻目标轮换两模式的先后次序。eval/test均为0，教师调用0，不训练adapter。基础Qwen3-4B-Instruct-2507版本cdbee75f17c01a7cc42f958dc650907174af0554，逐文件SHA核验本地下载清单；服务无adapter参数且拒绝adapter权重目录。

固定系统说明和公开原提示；用户主体前缀加历史后缀最多6400字符，系统另列；每次输出100 token、greedy、换行stop、每回合最多14个模型决定。think和错误决定都消耗一次调用；仅公开可见动作进入环境，不以隐藏目标修复。各回合seed从11起随决定编号增加。停止条件在生成过程中检测换行，若最后token包含换行后的文本，完整生成token仍计入消耗，返回文字截到第一换行。

## 启动条件与预算

冻结可在ALFWorld Stage 4运行期间完成；启动必须等待其100模型/6400回合、完整审计报告及execution completed，之后先核对完整结果。校准使用专门启动的基础服务，不复用此前任何adapter服务。GPU预检允许已逐身份验证且空闲的既有后台进程，拒绝其他计算进程或占用端口。

先在隔离CPU进程构造并验证train池，CPU准备最多900秒；成功后才启动GPU服务。CPU进程明确隐藏全部CUDA设备，原始环境在创建任何自动reset实例前限制train池，逐回合核对目标指纹。基础服务仅一个可见GPU、BF16/SDPA，8192上下文token，本地文件加载、禁止远程代码及网络下载。健康状态绑定子进程PID、版本、模型清单和权重摘要。

GPU时间从尝试启动服务之前计到GPU/CPU子进程全部停止后，包含校验权重、模型加载、失败、等待、终止；最多3600秒，预留20秒清理，达到停止时间即终止进程组。所有自有进程同时TERM，共享10秒宽限后KILL并回收；超预算明确记录，不能静默忽略。CPU准备失败且未尝试启动服务时GPU消耗0。硬杀后保留execution和子进程身份，不自动恢复或重跑，须先检查实际存活句柄并核算消费。

## 持久记录与报告

每个HTTP请求发出前fsync记录attempt；响应/异常分别追加记录，无自动重试。响应丢失、无效用量或被终止的请求标为未知用量，已知token合计明确标为known，不能将未知请求算作零成本。超输出预算的响应虽拒绝用于动作，实际返回的token仍记账。

逐回合目标、消息、响应和动作日志只保留本地，禁止上传。每回合目录独占创建，已有freeze/attempt不可覆写。汇总只含模式级完成数、严格成功率、连续得分、错误/思考/物理动作数、请求及token消耗、累计GPU时间，不含目标ID、任务文字或逐回合结果。若达到预算或中断，仅报已完成子集的描述性结果和缺失数，不将不完整、不配对的两模式均值作为方法比较。正式采集/SFT/测试和统计协议另行冻结。

## 执行

先通过CPU/回环HTTP测试，再冻结：

```bash
PYTHONPATH=src python3 scripts/run_webshop_pilot.py --freeze --gpu 0
PYTHONPATH=src python3 scripts/run_webshop_pilot.py --validate-only
```

只有父实验完成并核对后，使用主机权限和空闲GPU运行：

```bash
PYTHONPATH=src python3 scripts/run_webshop_pilot.py --run
```

当前协议在首个真实模型回合前固定；CPU测试和脚本策略的机械检查都不冒充模型性能。后续公开汇总与论文均保留这种区别。
