# 从 NLL 对照走向可干预的经验学习价值

状态：实施工作单，主学习实验尚未冻结。基础执行方式校准已完成，强梯度特征提取已单独冻结并运行，JSON兼容示例校准已排队；下列最终学生学习实验尚未执行。

## 保留的起点

Stage 5 已完成96个模型、6144回合。相同任务/动作/独特内容预算下，canonical low-NLL 相对随机的差值为 API −3.516pp、generic −3.060pp。此结果支持“单凭低动作NLL选样不可靠”，并留下三个可检验问题：中/高区间会怎样；结果能否推广到历史评测外；是否存在更接近实际学习收益的选择信号。新研究补这些证据，旧结果和版本继续保留。

研究对象先固定为**训练语料集合的价值**：原始训练单元是带上下文的动作监督样本，不把集合效果直接归因到某条完整轨迹。

\[
V_B(D;\theta,H,Q)=\mathbb E_{\xi,t\sim Q}
 [R(\mathcal A_B(\theta,D;\xi),H;t)-R(\theta,H;t)].
\]

这里B是明确的训练预算，H是固定部署执行方式，Q是独立任务分布。该式是研究定义，不是本项目已证实的预测公式。主问题是选择规则能否提高撤除采集辅助后的成功率；后续适应仍单列，避免强B训练抹平差异。

## 强基线的具体接入约束

[LESS论文](https://proceedings.mlr.press/v235/xia24c.html)与[官方实现](https://github.com/princeton-nlp/LESS/tree/8abf9628b9a814ac3045445eebc8ba3c908fdc78)包括LoRA预热、训练候选的Adam状态相关更新特征、目标支持样本的SGD梯度、投影和跨checkpoint加权匹配。普通初始梯度余弦只能叫梯度对齐基线，不能直接写成完整LESS复现。

接入时先确定独立目标支持数据。可行候选是公开放置/清洗示例，其重置指纹已与新任务排除重合；需要在单独规范中固定轨迹解析、JSON重建、assistant-only mask、长度资格与逐样本权重。公开示例不等于新任务监督，不得用新开发/确认回合的答案反向选样。

最终SFT预算相同与总成本相同分别报告：LESS预热、特征提取、目标监督不能算免费。若增加目标支持监督，应给随机方法同等支持数据的对照，隔离额外监督本身的收益。对所有选择规则保持相同任务/动作覆盖约束，并另外报告不加覆盖约束的标准选择版本，说明与原论文的差异。

## 两层后续实验

第一层补齐现象：低/中/高/随机/强梯度选样，两个来源，同一训练起点和部署H，报告训练起点、训练后成功率、独立种子差异与实际token/耗时。开发任务用于方法研究；确认任务只在方法、主要对比、样本量和统计方法全部固定后开启。原有冷却/加热任务仅作历史复现坐标。

第二层检验学习价值预测：单位是固定大小、固定任务覆盖的语料集合；先在开发阶段预定少量候选预测器，再训练多个集合取得真实收益。验证按采集条件分组，集合不能混入训练/验证两侧后声称跨harness泛化。现在只有两个历史来源，不能据此宣称广泛跨harness规律。预测之后还要在同一采集池内做高预测值/低预测值/随机干预，并控制样本、任务、动作和训练预算。
