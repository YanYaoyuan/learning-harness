## 一个可测量的定义

设初始学生为θ，训练算法为A，固定训练预算和配置为B，部署harness为H，评测任务分布为Q，训练与执行随机性为ξ。以数据集D作为当前实际训练的单位：

\[
V_B(D;\theta,H,Q)
=\mathbb{E}_{\xi,\,t\sim Q}
\left[R\!\left(A_B(\theta,D;\xi),H;t\right)-R(\theta,H;t)\right].
\]

这是后续研究定义，不是本文已经证实的公式。B需要明确优化器、更新次数、呈现次数和参数化，并单独报告token消耗；相同呈现次数不称为相同FLOPs。H是部署时的执行方式，须与产生数据的采集harness区分。

本轮实验直接估计的是相同初始学生、预算、评测集和部署方式下的相对收益：

\[
\Delta V_B(D_{\mathrm{select}},D_{\mathrm{random}})
=\mathbb E[R(A_B(\theta,D_{\mathrm{select}}),H)]
-\mathbb E[R(A_B(\theta,D_{\mathrm{random}}),H)].
\]

相同的基础模型项在这里消去。既有负差支持所测选样策略的相对表现，不能据此识别每条经验的独立价值。单条经验的边际作用还依赖它替换或加入的数据、训练顺序和其他样本之间的交互。先以训练corpus为分析单位更贴近可验证的实验。

## 高／中NLL对照的CPU可行性

使用已完成的统一评分、原Stage 4任务×动作参考、四个原采样配方，分别生成random、low、middle、high名单并核对约束。未调用模型、训练或运行新环境回合；原冻结配方未变。Middle精确定义为：在每个任务×动作层中，优先选择距该层不同内容NLL中位数最近的K条；high选择最大NLL的K条。支持数、呈现次数和逐位置任务×动作保持一致。

| 来源 | low与high替换内容/256 | low与middle替换内容/256 | 没有选择余地的内容配额/256 |
|---|---:|---:|---:|
| API | 106–109（41.4%–42.6%） | 24–32（9.4%–12.5%） | 81–98 |
| Generic | 161–166（62.9%–64.8%） | 54–66（21.1%–25.8%） | 41–59 |

所有八个来源×配方检查通过。High与low的选择分离充分，middle与low仍有较大重合。层内中位数选择不能被默认为全局“中等难度”，特别是在偏斜分布及强支持约束下。正式方案应预先报告干预强度和被迫保留的内容，而非训练后按效果调整定义。

完整扩展middle/high两臂到当前六初始化×四配方×两来源需要新增96模型/6144回合。它应与新任务评测和统一预算一并固定，避免只增加原开发集上的重复数量。[可复算的汇总检查](../output/research-operations/20261113/nll-range-control-feasibility.json)

## 提升论文说服力的顺序

1. **完成正在运行的统一评分复现。** 保留全队列、所有配对、绝对分数和逐初始化值，报告新随机相对旧随机的变化，防止将跨运行波动全部归因于评分。
2. **固定新任务与部署方式。** 核对训练/示例/反复使用的开发任务排除后，冻结新任务清单；同一套训练权重在共同JSON和共同强执行方式下分别测量。H作为被评估因素，不能因某策略得分更高而换H。
3. **补充high/middle与强对照。** 先确认选择单位、候选池、任务覆盖、内容数和训练量一致，再固定新任务上的终点。完整轨迹方法需要真实多候选池，当前动作级baseline不能冒充完整SmartAD。
4. **预测器加干预。** 以不同但覆盖匹配的corpora为样本，比较候选指标对post-SFT增益的预测，按采集条件分组留出验证；检验其相对NLL、成功率、覆盖、长度等简单因素是否有增量信息。冻结预测器后，在同一候选池内做高分/低分/随机选样干预，并用独立任务评测。
5. **独立学习环境。** 复用WebShop已验证的基础接口，另外固定候选经验池、选样、SFT和新任务终点，验证学习效应而不仅是模型能够调用环境。

本顺序不预设预测器必须成功，也不把形式化定义当作新颖性或结果。若目标是有机制贡献的论文，预测与干预都应成为证据。

## 梯度方向应作为强基线，而不是先验的新方法

原始NLL衡量学生对已出现目标的可预测性，不直接测量一次参数更新与目标任务的关系。梯度对齐可作为一个候选代理，但它涉及目标支持数据、优化器预条件、长度及格式偏差，需要同等信息和成本核算。LESS已提供optimizer-aware gradient features的直接先例；应实现并比较，而非把“使用梯度”本身命名为贡献。[LESS官方论文页面](https://proceedings.mlr.press/v235/xia24c.html)

若使用目标梯度，支持数据必须来自与最终新任务独立的允许集合；不能用评测答案构建选择器。最终能支撑更强主张的证据，是代理在新corpus/采集条件上预测实际增益，并且按该代理选样确实改变收益。
