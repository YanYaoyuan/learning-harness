# 已完成实验审查：保留证据，收窄结论

日期：2026-11-10。范围：现有文本 ALFWorld 实验；不启动新训练、API 调用或具身平台迁移。本报告是事后分析，不改变原预注册主指标，不将新诊断包装成确认性结果。

## 结论先行

现有证据支持：支持策略改善采集；API 来源经验在部分任务上形成更好的无辅助起点和适应期间表现。尚未支持：跨任务族的通用学习能力增强、纯可塑性提升、RSI。主交互不显著不能用于否定上述所有收益；次级正结果也不能替代未获支持的主假设。

最值得保留的是“经验内化具有任务依赖”这一探索线索。最新逐步审计还表明，最终剩余失败主要卡在拿取目标之前，原有成功轨迹上的 NLL 不能充分测量自主执行瓶颈。这些线索需要有针对性的鉴别，不足以直接宣布新机制或转向新领域。

## 1. 审查了什么

新增脚本 `scripts/audit_completed_experiments.py` 直接重读 API 采集的 432 个 episode、最新 factorial 的 7,200 个主评测 episode，并逐动作分析全部 960 个最终 B 回合。重建的每个条件、种子、检查点成功率、A 保持率与原报告一致；原始 AUC 点估计一致。审查 manifest 后，两族各自的教学 48、校准 12、诊断 8、B query 32、A query 24 任务组相互隔离。组隔离不等于房间或预训练内容隔离。

输出：`output/research-audit/2026-11-10/audit.json`、`input-sha256.json`、`final-trace-audit.csv`，以及三张 PNG/PDF 图。输入和审计代码有 SHA-256；新文件不覆盖原实验产物。审计额外计算的区间使用 NumPy RNG，对原报告使用的 RNG 不作逐样本复刻，端点有小幅 Monte Carlo 差别；以下主要结果沿用原冻结报告的区间。

另核对 v1、v2、filtered、learning-speed、API 学习报告及实际训练实现。早期报告的结果复读与最新 7,200 回合的独立重建应区分；没有声称重新逐回合重建全部历史实验。

## 2. 各轮实验真正留下了什么

| 实验 | 结果 | 合理结论 |
|---|---|---|
| v1：单训练种子探索 | target SFT / mixed SFT / context distill 的支持来源平均差均为正，但只有 12 个开发任务 | 证明流程能运行，给出候选信号；不能判定方法排名或通用效应 |
| v2：扩大采集与三种子训练 | 早期提示采集 57/192，无提示 22/192；任务组差 +18.82pp，95% CI [11.29,26.88] | 即时采集收益得到支持 |
| v2 原始、匹配、过滤后的新 28 题 | 支持−无支持分别 +5.95、+2.38、+8.33pp；三者区间均跨零 | 不支持稳定排序反转，也不能当作支持无效的证明 |
| learning-speed：新冷却任务 | early−none 原始 AUC +1.48pp，CI [-6.51,8.85] | 当前精度下来源差异不明确；共同 B 教学确实能让模型学起来 |
| API 采集 | none 25/144，generic 49/144，API 68/144 | 更具体的公开策略提示改善采集，非仅“换一个大老师”的推测 |
| API 第一轮后续适应 | API−generic 原始 AUC +5.60pp，CI [-1.39,14.06]；三种子方向均正 | 有正向线索，证据仍不精确；与最新 matched 条件复用 A 模型，不能算完全独立复现 |
| factorial：来源×筛选规则 | 跨族原始 AUC 交互 +1.38pp，CI [-6.19,8.06] | 预设交互未获稳定支持；该检验不等于 API 平均作用为零 |

正负两面都要保留：多轮点估计偏正不能将有关联的实验简单累加成独立证据；多个区间跨零也不能被串起来变成“全部没有效果”。

## 3. 采集收益明确，但“更好数据”需要分解

API 轮三条件各 144 次回合。成功任务组为无提示 15、通用提示 29、API 35；API−通用的任务组平均成功率差 +12.68pp，CI [4.93,21.13]。整体回合成功率为 17.36%、34.03%、47.22%；组加权与回合加权略有差别，不混用。

API 的成功回合平均 10.88 步，通用提示 16.02 步。这个比较受成功任务构成影响，不能直接当作相同任务的因果效率提升。学生采集输入 token 总量从通用的 3,749,324 降至 API 的 3,095,257，输出从 52,736 降至 43,563；这是学生端计数，未合并教师成本或执行延迟。

API 成功更多却产生更少原始动作样本（740 对 785）；去掉字面 `Nothing happens.` 后为 721 对 732。因而成功数量、任务覆盖、轨迹长度、动作质量不是同一个指标。API 成功轨迹中被过滤的无效反馈标签为 19，通用为 53，这支持经验构成改变，但不证明某一个成分导致后续收益。

## 4. 匹配加热条件是值得保留的正结果

以下均为 API−通用提示；AUC 是成功率在 0–128 次更新区间上的归一化面积。

| 条件 | 初始成功率差 | 原始 AUC 差及原报告 95% CI | 最终成功率差 |
|---|---:|---:|---:|
| 冷却，matched | 0.00pp | -1.99 [-7.55,3.61] | +3.13pp |
| 冷却，full | +7.29pp | +3.45 [-1.20,8.63] | +4.17pp |
| 加热，matched | +10.42pp | +7.91 [2.38,14.23] | +3.13pp |
| 加热，full | +11.46pp | +5.24 [-4.39,14.55] | 0.00pp |

匹配加热的 API 原始 AUC 在三个种子分别高 +5.27、+6.74、+11.72pp。初始成功率为 API 17.71%、通用 7.29%；最终为 85.42%、82.29%。这应表述为在该任务族和实验条件下，API 来源有更好的起点和适应期间表现，最终差距缩小。它是次级结果，未作多重比较校正，不能单独承担整篇论文。

该正结果不是简单由“API 训练了更多加热样本”解释：matched 使用同一批 13 个任务组，各 182 条独特动作示范，实际各处理 256 条；三个种子的加热任务动作样本数两来源分别同为 12、11、11。匹配索引安排也相同。这排除了任务组数量和该层样本数量的差异，仍未排除路径、历史、标签选择、信息量与目标 token 的差异。

full 的差异更复杂：通用每种子实际见到 10–12 条加热任务动作样本，API 为 40–49 条；因此 full 加热的收益可被直接任务暴露量解释一部分。full 加热初始来源差在三种子为 +15.63、+43.75、-25.00pp，不能只报均值 +11.46pp 掩盖不稳定性。

加热目标族在 A 数据中出现；冷却目标族没有出现。加热较强、冷却不稳定，与任务相关经验迁移相容，但两族本身也有难度、对象、查询实例等差异，不能直接证明“已见目标族导致收益”。

## 5. 起点与学习必须分开，已有内化证据不应抹掉

独立诊断轨迹上，A 后初始 NLL（越低越好）：

| 条件 | 通用提示来源 | API 来源 |
|---|---:|---:|
| 冷却 matched | 0.5904 | 0.3304 |
| 冷却 full | 0.5683 | 0.2907 |
| 加热 matched | 0.3972 | 0.1803 |
| 加热 full | 0.3445 | 0.1341 |

评测时外部提示已撤除。这说明训练来源确实改变了模型在这些独立参考上下文中的动作预测，和“完全没有学进去”不符。但 NLL 降低不自动等于自主任务完成，也不是纯学习能力的指标。

归一化 `gain AUC = raw AUC - initial score` 是恒等式。匹配加热原始差 +7.91pp，减掉初始差 +10.42pp 后，gain 差就是 -2.51pp。这不能解释为 API 损害学习能力，也不能反过来据原始 AUC 就宣布学习速度提高；两者都混有先验知识与执行瓶颈。

当前原始 AUC 按更新数线性积分，64–128 段占总区间的一半。它测的是整个预算区间的表现，不是专门测早期适应速度；对曲线只保留一个面积会隐藏中途交叉。保留所有检查点与种子曲线比事后更换积分权重更合适。

实际参数化是冻结基础模型与 A LoRA，仅训练新增 B LoRA。该设计让 B 更新范围、初始化和样本顺序具有可比性，是有价值的控制；同时它不等于继续更新同一组 A 参数，不能测一般意义的可塑性保持。B 的 512 条样本顺序、token 预算和更新规则在同一任务族的各条件一致。A 只配平了样本数与更新数，没有配平所有 token 和语料重复率。

matched 的 182 条示范在 256 次抽样中全部覆盖并有重复；full 的 721/732 条池仅取 256 条不同示范，实际任务覆盖为 API 34–35、通用 29。full/matched 同时改变覆盖、重复和动作分布，因此主交互不能单独识别“覆盖收益”。

## 6. 新的逐动作诊断：剩余瓶颈多数在取得目标之前

对全部最终 B 回合而非精选失败案例进行事后规则审计。通过公开任务说明抽取目标类型，用环境反馈 `You pick up the ...`、`You cool/heat the ...` 确认里程碑。全部成功回合都通过拿取及处理里程碑检查。

| 最终回合分类 | 冷却 | 加热 |
|---|---:|---:|
| 总回合数 | 480 | 480 |
| 成功 | 349 | 396 |
| 失败且未成功拿取目标 | 121 | 82 |
| 已拿取目标，但未观察到处理成功 | 8 | 1 |
| 已处理，但未成功完成任务 | 2 | 1 |

共 215 次失败，203 次（94.4%）未成功拿取目标；所有失败用尽 40 步。它们是 64 个 B 任务在 15 种模型/种子组合下的重复评测，不是 215 种独立失败任务。

进一步事实：

- 失败回合中，冷却 104/131、加热 33/84 曾成功拿起非目标物体。
- 未取得目标的失败中，冷却 34、加热 46 次已经在公开返回观察中看到目标类型及编号；不能统一归因为找不到目标。
- 冷却 131/131、加热 67/84 次失败重复了相同导航命令与相同返回观察；这种重复也可能是必要回访，不能直接叫错误循环。
- 冷却 6/32、加热 3/32 个任务，在所有 15 个最终模型上均失败；冷却 21/32、加热 22/32 全部成功。多数终点表现由共同容易/困难任务决定，进一步限制了来源比较的信息量。

一个可复查的例子：匹配 API、seed1101、冷却 Mug→Cabinet-22 任务，模型先拿了 apple，随后看到 mug、尝试拿取却收到 `Nothing happens.`，又尝试冷却未拿到的 mug。另一个加热 Plate→CounterTop-5 任务，在第 2 步已看到 plate，随后仍继续搜索。这些是说明行为的例子，统计来自整个最终队列。

初始任务说明始终留在 prompt 中，只有动作历史截断为最近 12 步。因此拿错目标不能直接归因为任务目标被截掉。现有证据允许考虑目标条件化不足、错误持有状态恢复不足、搜索策略、历史截断和 40 步预算等解释；尚不能决定哪一个是主因。

所有条件最终诊断 NLL 约 0.0006–0.0029，但独立完整任务成功率仍约 71–85%。诊断采用成功参考轨迹上的固定正确历史，不是学生偏航后真实访问的状态，两者差异并不矛盾。诊断任务也不同于 query，不能宣称逐任务预测失效已被证明。可信的结论是：当前 NLL 诊断不足以说明自主执行瓶颈是否被解决。

## 7. 目前能排除、不能排除的解释

| 解释 | 当前判断 |
|---|---|
| 后续差异只是测试时还在接受 API 帮助 | 已核对各回合 `support_injected=false`，不支持此解释 |
| 某来源 B 阶段用了更多数据/更新 | 同任务族 B 序列、预算、更新规则有控制，不支持此简单解释 |
| 所有来源训练完全没形成可保留变化 | 独立 NLL 与部分无辅助起点/曲线差异不支持此笼统判断 |
| matched 加热只是 API 见过更多加热动作样本 | 实际样本数一致，不支持此数量解释；内容仍不同 |
| full 加热只是 API 多见了相关任务 | 暴露量差异确实存在，不能排除 |
| 来源效果不稳定来自少种子、少任务或复用采集数据 | 不能排除，且部分条件种子波动很大 |
| 来源改善了知识/策略先验，未改善一般学习能力 | 与现有数据相容，是优先保留的解释 |
| 共同的目标选择/恢复瓶颈压低了后期来源差距 | 逐步轨迹支持进一步检验，尚未做因果干预 |
| 加大模型或换具身环境就会让效应成立 | 没有依据，不据此扩规模或迁移平台 |

## 8. 对下一步的约束

当前保留原研究主线，具身建议仅作候选，不能自动成为执行计划。先不再扩大 matched/full 网格。

优先做的最小鉴别应围绕已经出现的两条证据：一是匹配加热的无辅助收益是否在新采集/新任务上保持；二是参考历史预测与真实偏航状态之间的差距。后者可先在冻结 checkpoint 上比较“看见目标后的正确拿取”“拿错物体后的恢复”等状态的行动选择，结合现有完整轨迹验证，不需要立即训练一个新 harness。

如果确认有稳定的任务相关内化但没有一般学习加速，研究结论可以收窄到经验的可迁移性与执行条件，保留正结果。如果发现效果主要由直接任务暴露或简单既有基线解释，应据证据收窄创新性判断；不为了维持最初标题把普通迁移改称元学习。

这批实验尚不足以独立支撑一篇强方法论文，但也不是“已经证伪、全部作废”。当前更准确的结论是：采集收益有证据，任务相关的内化与适应收益有值得复查的信号，通用学习能力的强主张尚未建立；已有评测把目标选择、搜索、恢复与目标操作混合到一个成功率里，需要进一步拆解。
