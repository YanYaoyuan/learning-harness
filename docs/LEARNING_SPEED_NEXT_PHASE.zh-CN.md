# 新任务适应：设计与完成结果

执行状态：**原九条主比较与 API 后续九条适应轨迹均已完成。** 固定公开文本参考策略在 48 个教学任务上全部成功，得到 462 条有效动作示范，并冻结了所有学生共用的 512 条序列。三个基础模型种子均从 1/12 提高到 11/12，预设校准门槛通过后才开放主 query。原实验文件位于 `runs/learning-speed-v1/`，该轮不调用付费 API，两轮均未使用官方 seen/unseen 最终测试。

2026-11-10 结果核查：原实验 early−none 原始 AUC 差为 +1.48 个百分点（95% crossed bootstrap 区间 [-6.51, 8.85]），gain AUC 为 +2.86（[-13.28, 17.97]）。128 步时 base、none、early 的三种子平均 B 成功率分别为 87.50%、86.11%、88.89%。在目前三个种子、24 个 B 任务和四个检查点下，没有稳定的来源优势证据。

API 后续共完成 432 个采集回合、9 个 A 训练、9 条 B 适应轨迹和 1,944 个评测回合。无提示、通用提示和 API 策略分别成功 25/144、49/144、68/144；API−通用提示的任务组平均采集增益为 +12.68 个百分点，95% 配对任务组 bootstrap 区间 [4.93, 21.13]。采集收益有明确证据。

三来源共同成功的 13 个任务组通过预设门槛，各匹配 182 条有效示范，A 阶段各实际处理 256 条示范。API−通用提示的后续原始 AUC 差为 +5.60 个百分点（[-1.39, 14.06]），gain AUC 为 +1.43（[-7.90, 10.20]）；两者相差 4.17 个百分点来自初始成功率差，这只是指标分解，不能当作因果机制。128 步时三来源 B 成功率为 79.17%、81.94%、80.56%。初始共同 B 材料的 token NLL 均值约为 0.683、0.644、0.403，说明来源已改变模型对这些材料的预测，不能将后续差异纯粹归因于可塑性。

下一阶段应先解决识别问题：当前匹配只保留三来源共同成功任务，排除了 API 独有成功任务的覆盖收益；只有三个种子且 B 只有冷却任务，区间仍宽。因此不把本轮包装为 RSI 或学习能力提高，也不因区间跨零断言无效。建议预先冻结“全采集分布总效应”和“共同任务条件效应”两条对照、增加独立任务族，并设计起点能力控制；不根据已看过的 query 反复调整本轮筛选规则。当前图及 CSV/PDF/SVG 已导出，主要结论由 `main-result.json` 的实际回合统计支持。

## 这一阶段已经说明什么

1. 在当前设置中，早期支持的采集成功数为 57/192，无支持为 22/192；成功任务覆盖为 32 对 14。它确实改变了采集结果与后续训练数据。
2. 训练后来源差距在不同种子间换方向。原始与匹配各有 1/3 种子反转，过滤后为 0/3；所有平均效应区间跨零。稳定反转没有成立，等效或修复机制也没有成立。
3. 匹配控制任务/采样种子与动作示范数量，未控制全部历史、标签、token 和轨迹质量。过滤还重配了示范分布。残余差距不能自动叫作“学习者更强”。
4. 大部分增益集中在放置和清洗；冷却、加热接近地板。当前的短训练终点评测没有直接测后续学习速度、持续学习或在线 RL。

固定离线更新可记为 `theta_A(h) = Update(theta_0, D_A(h))`。当前主要比较不同训练数据诱导的终点。接下来要对所有起点使用**完全相同的新数据 D_B 与更新规则**，观察 `J_B(theta_A(h), k)` 随 B 阶段更新数 k 如何变化。这仍是有条件的适应效率测量；更快的曲线可能来自先验知识，不自动等于通用元学习能力。

## 明确的下一步

先做“基础模型能否在该 B 材料上学起来”的正控制，通过后才运行三种初始化的配对学习曲线。

| 项目 | 已准备的设计 |
| --- | --- |
| A 初始化 | 过滤且匹配后的无支持来源、早期支持来源，各 seed 101/202/303；再加基础模型对照 |
| B 任务族 | 冷却后放置；该目标族未进入上述 A 初始化的训练示范 |
| B 数据划分 | 48 个教学候选任务、12 个 calibration、24 个 query，均为此前未使用的训练池任务组 |
| 旧能力保持 | 原开发 probe 中另外三个任务族的 21 个任务，逐类报告 |
| B 检查点 | 同一条连续训练轨迹的 0、8、32、128 次更新 |
| B 预算 | global batch=4，128 次更新共 512 条样本；B 数据和样本顺序在所有起点间相同 |
| 训练重复 | 三个配对 A/B 种子，共 9 条轨迹；数据种子固定 777 |
| 正式测试 | 不运行 seen/unseen；B query 不能用于教学材料或超参数选择 |

冷却目标族不在 A 训练示范中，不代表模型预训练时未见过冷却概念、工具语法或 ALFWorld。任务组互斥也不等于房间互斥。当前只选一个 B 族作 pilot，不据此声称跨任务族的通用元学习。

补充数据审计见 `runs/learning-speed-v1/a_exposure_audit.json`：两份 A 语料各 255 条示范，均无 `cool` 动作目标标签；共同系统提示在全部示范中都列出了冷却语法。因此可以排除直接冷却动作标签这一项来源差异，仍不能排除预训练知识、共同提示与导航/操作经验的迁移。动作类型分布也未被数量匹配控制，例如 `look` 在两份语料中分别为 45 和 30 条；这只是语料组成，不能直接当作已执行训练次数或可塑性机制证据。

## 共同教学材料与可学习性校准

用一个固定参考策略、仅依赖公开观察，在 B 的 48 个教学候选任务上生成成功示范。可以先尝试本地参考策略加可复用技能示例；此策略不随学生条件改变。参考策略若太弱，应先加强教学材料，不能让不同学生分别收集自己的材料来替代共同数据对照。API 保持用户先前的延后设置。

在任何主 query 评测前，冻结一份公共 `D_B`：至少覆盖 12 个成功任务组、200 个通过上下文上限检查的动作示范，保留采集失败及成本。按任务组平衡安排 512 条样本，生成一个所有学生共用的抽样计划。初始不因这轮过滤结果假定某类反馈必然是坏标签；示范反馈组成需报告，材料版本在 query 前锁定。

仅在 12 个 calibration 上检查基础模型的三条学习曲线。工程上的通过门槛预定为：至少两个种子在 128 次更新后，比各自第 0 步多完成至少 2/12 个任务。这是测量可学习性的门槛，不是统计显著性或 harness 有效性的检验。

不通过时，先修教师、材料、训练预算或环境设置；不要把低分或平曲线当成“所有 harness 没有学习作用”。B query 此时不开放。

## 固定材料下的适应比较

正控制通过且材料/超参数冻结后，运行 9 条主比较：基础模型、A 无支持来源、A 早期支持来源各三个配对重复。优化器在 B 起点全部重置。

为避免 A 阶段已经消耗 LoRA 容量或保留优化器动量，优先冻结原 A adapter，添加同初始化、同秩的 B adapter；基础模型使用对应的零 A 分支以匹配参数化。实现前必须验证第 0 步输出与原起点的一致性，不默默合并 BF16 权重后把数值变化当成学习。

每条轨迹连续训练到 128 步并保存 0/8/32/128 检查点；不能分别以四种终止步数重开训练、改变学习率日程后拼成一条曲线。B 样本清单和顺序固定，优化器/随机性在配对条件中对齐。checkpoint 都在 H0 下评测，禁止教学提示进入 query。

主要报告：

- B query 的完整成功率曲线，显示每个种子和配对不确定性。
- 归一化曲线面积：对 0/8/32/128 步作梯形积分再除以 128。
- 相对各自第 0 步的 gain AUC，以及第 0 步成功率和共同 B 示范上的初始动作 NLL。
- 128 步终点与 A 旧能力保持；按任务族分解，单独标明地板效应。

较高终点可能是起点就更强；较大增益也可能受天花板影响。初始能力和初始 NLL 明显不同时，应称为有条件的迁移/适应差异，不能直接归因于“可塑性”。三个配对 A/B 重复也没有分离所有数据与优化随机性。

## 扩样条件

若正控制可学，但两种 A 起点的增益曲线没有一致方向，暂不放大当前通用提示设定；先检查功效与干预强度。不能用不显著宣布等效。

若三个配对种子方向一致，且归一化 gain AUC 差距至少 0.05，可作为值得扩样的候选信号；这仍不是论文级确认。下一步需要更多种子、第二个 B 族、第二个学生模型。更换 B 族时应重新构建排除该族的 A 训练，而不能假装已有 A 模型从未训练过它。

只有适应差异在这些检查及强内化/蒸馏对照后仍成立，才研究机制或预测器。只有跨任务/模型预测也成立，才投入学习型 harness 或 meta-RL。当前只有无支持与一个通用早期提示，两种来源不足以建立可迁移的 harness 预测规律。

## 2026-11-10：来源与筛选规则的后续实验

后续实验冻结 `runs/transfer-factorial-v1/design.json`。以通用/API 两种来源和 matched/full 两种经验筛选规则构成四个条件，另设无 A 阶段基础模型。matched 精确复用上一轮三方共同成功的 13 组、各 182 条示范及其六个 A adapter。full 从已采集数据的全部合格成功经验抽样，通用来源 732 条、29 个任务组，API 来源 721 条、35 个任务组。两者均训练 64 步、实际处理 256 条示范，token 数分别记录，不宣称相等。新训练六个 A adapter。

冷却与加热各做 15 条 B 轨迹，共 30 条。冷却目标未用于 A 训练；加热目标已用于 A，属于新实例迁移。二者不能混称为新技能。为保留原最终跨任务族检验，双物体与灯光任务仍不进入教学或选择。冷却只剩 52 个未使用训练任务组，因此复用已有 48 个冷却教学任务，52 个新组严格分为校准 12、诊断 8、query 32；加热使用新的 48/12/8/32 组。两族及 A 保持集共 24 组之间按任务组隔离，官方最终测试未使用。

两族参考教学采集均成功 48/48，诊断任务各成功 8/8。有效教学动作分别为 459 和 555 条，任务均衡构造各 512 条共享 B 序列；诊断各保留 60/62 条动作，始终标为 dev，禁止进入优化器。每条轨迹在 0/8/16/32/64/128 做 32 个 B query 评测，0/128 做 24 个 A 保持评测，共 7,200 个主评测回合。两族都要先在三个 base 种子中至少两个获得校准集 12 题上至少 2 个额外成功，才开放任何新 query。

主指标是每族 `(full-api − full-generic) − (matched-api − matched-generic)` 的归一化原始 AUC，再取两族等权平均；同时报告每族效果、gain AUC、初始成功率、动作 NLL 轨迹与保持端点。bootstrap 以配对种子和任务组为单位，同一重采样种子索引跨族共享。NLL 降幅与 gain AUC 均只是诊断，不能作为纯可塑性因果证据；三种子统计仍较弱。full/matched 同时改变覆盖、动作构成、样本池大小与重复率，不能从交互效应单独识别某一个机制。

预实验发现 GPU/BF16 训练的逐位重现性不足：在不同卡做带/不带诊断对照后观察到参数差异，同一张卡不带诊断重跑也存在最大绝对差约 0.000488。不能把差异归因于诊断本身。保持科学设计、数据划分、训练预算和校准门槛不变，在 query 未开启时记录 `protocol-amendment-001.json`，恢复原训练脚本，将诊断移动到训练结束后的独立进程。对 0/8 步验证检查点的读取前后文件哈希完全一致，隔离检查通过。原失败记录与修正前代码哈希保留，不能隐去失败或声称获得了逐位确定性。

运行入口为 `scripts/run_transfer_factorial.py`，报告入口为 `scripts/transfer_factorial_report.py`。所有正式结果仅由完整回合生成，自动导出 PNG/PDF/SVG、逐回合 CSV 和可独立重画的 measured-data.json。W&B 使用独立观察器记录两个任务族；训练进程不依赖云端服务。当前运行状态以目录中的执行和进度文件为准。


本轮收尾：30/30 条轨迹、7,200/7,200 主评测回合均完成，训练与评测进程已退出。预设跨族等权主交互效应为 +1.38 个百分点，95% crossed-bootstrap 区间 [-6.19, 8.06]；gain 交互为 −2.78，区间 [-19.58, 14.03]。此主指标检验的是筛选规则是否改变来源效应，不是直接检验 API 的平均主效应。跨族主假设未获稳定支持。
