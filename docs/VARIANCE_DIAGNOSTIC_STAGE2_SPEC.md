## 两个新组

- `full_pass`：从固定721条API或732条generic全池进行完整随机遍历，再补足至768次呈现。
- `subset_replay`：取同采样种子对应的原256条子集，随机重排后训练3遍，恰好768次呈现。
- 每组固定192次更新、batch 4；首256个样本索引一致，初始化/dropout种子一致。学习率及所有其余训练超参数一致。
- 沿用4×4初始化/dropout种子与采样种子，各来源16个主单元，再各加一次101/101条件训练重复。两个新组合计68个模型。
- 两组每个对应单元使用相同物理GPU；沿用Stage 1的分卡，并交替两组执行顺序。
- 原256呈现的Stage 1只作历史剂量参照。主比较是两个768呈现的新组之间的采样策略效应。

历史64步与新192步的学习率调度长度也不同；首256个样本索引一致不代表历史模型与新模型在64步时权重一致。

全池策略同时改变示范覆盖、出现频率与后续顺序；不将结果单独归因于任务覆盖。记录实际独立示范数、任务数、任务类型次数、输入/目标token及采样哈希。两组更新数和样本呈现数相等，token数如实单列。
