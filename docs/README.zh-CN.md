# 从执行到学习：智能体经验选择

[论文](https://arxiv.org/abs/2611.27159) · [PDF](https://arxiv.org/pdf/2611.27159) · [实验索引](EXPERIMENTS.md) · [运行说明](REPRODUCIBILITY.md)

本项目研究成功交互记录的训练价值：在相同训练预算下，哪些动作经验更适合用于小模型 SFT，选样规则与任务覆盖约束又如何共同影响结果。

论文使用 Qwen3-4B-Instruct-2507 和 ALFWorld 文本环境，在两个固定经验池上比较九种选样规则。八个初始化种子与两个采样种子共得到 288 个学生模型。每个学生使用 256 条不同内容、768 次样本呈现，并通过统一执行器完成评测。

## 主要结果

| 全局选样规则 | 开发集 API | 开发集 Generic | 保留集 API | 保留集 Generic |
|---|---:|---:|---:|---:|
| 随机 | 73.19% | 67.24% | 66.65% | 60.06% |
| 高 NLL | 77.34% | 69.14% | 68.80% | 61.91% |
| 优化器感知梯度 | **81.45%** | **73.19%** | **71.63%** | **69.14%** |

保留集包含 128 个与开发面板分离的任务组。复用 97 个检查点完成 12,416 回合后，两个来源等权的梯度选样收益为：相对随机 **+7.03 个百分点**，相对高 NLL **+5.03 个百分点**。

梯度分数沿用 LESS 的构造。本研究考察选样规则在相同预算、匹配覆盖和自由覆盖下的表现。实验基于官方训练池划分的开发与保留任务，未使用官方 seen/unseen 测试集；重复持续学习周期和长期保持不在本次评测范围内。
