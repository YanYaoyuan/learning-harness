# 新任务上的经验学习价值：开发学习对照

状态：在新开发任务首次模型调用前冻结。本阶段用于评估选择规则和为后续独立确认取得效应与方差；不将开发数据报告成预注册确认结果。原128确认任务及官方seen/unseen不执行。

## 科学问题和比较

在相同训练起点、样本呈现预算与部署接口下，优化器感知梯度选样是否优于随机及简单高NLL？在同一经验池内，高/低梯度分数选样是否改变实际训练后任务成功率？低/中/高NLL用于检查NLL关系是否非单调，防止将“高NLL选择”误认为新的梯度机制。

七条件：random、low、middle、high、gradient_high、gradient_low、gradient_global。前六条件保持参考调度的逐位置任务/动作类型与每任务/动作的不同内容配额；gradient_global为不加覆盖约束的全局top256不同内容，单列为强排序基线，不能把其差异解释成覆盖受控干预。

每份清单768次呈现、256个不同任务内容。中NLL取每任务/动作层内不同内容NLL中位数附近；梯度高/低按已完成FP32四检查点评分正/反向排序。同来源、同采样种子下两者的任务/动作/独特内容预算相同。

- 一个未训练基础模型另评测一次；每模型128个已固定的新开发任务（放置/清洗各64），合计225×128＝28,800回合。所有128任务完整使用，不根据结果抽子集。与校准32、确认128按任务组隔离。
- 所有学生从Qwen3-4B-Instruct-2507原基础模型、revision `cdbee75f17c01a7cc42f958dc650907174af0554`冷启动；不使用梯度特征模型的预热权重。LoRA r16/alpha32/dropout0.05、q/k/v/o_proj，192个优化器更新、batch1累计4、lr1e-4、warmup_ratio0.05、weight_decay0、max_length2048。复用未修改的历史编码、Trainer、外部调度和拆分种子实现；实际token逐模型核对，固定呈现不称严格同token。

- 推理使用同一不可变zero-B分支与各自A，以保持既有组合加载端口；从历史B导出中精确提取活跃的lora_A/lora_B张量、核验活跃B矩阵全零，排除其中附带的外部A命名键，原历史文件保持不变。B不更新，目录链接避免重复复制权重。不合并BF16权重。基础模型条件不加载adapter。

## 顺序、统计和中途报告

16个完整初始化×采样块，每块包含七条件×两来源。块内固定顺序random、gradient_high、high、low、middle、gradient_low、gradient_global，来源交替。先训练并评测第一个学生，随后评测未训练基础模型；之后完成所有预定条件，不据胜负改顺序或删条件。

主要开发终点为训练后成功率；先分别对来源和采样种子均衡平均，再列八个初始化值。主要预定描述性对比为gradient_high−random、gradient_high−high，以及同池干预gradient_high−gradient_low；global条件单列。记录基础模型差值、各族、格式错误、每模型tokens、GPU时间和全部负向结果。

16个块全部完成为主报告。只在1/2/4/8/16个**完整均衡块**后生成固定中途图；保留所有节点，不提前按收益停止，也不以中途图选择论文主结果。进行中的半个块只显示进度。

本阶段不报告显著性、未经离散结果校准的少种子百分位bootstrap区间或“等效”。最小关注效应暂定5个百分点作为随后确认样本量规划目标，当前不承诺80%功效。完成该固定开发矩阵后，按实际二值配对数据、任务/初始化/采样及评测噪声分量校准确认分析和功效；确认集保持封存，确认协议与新增种子另冻。本阶段不能替代第二环境学习复现，也不是已完成的语料价值预测验证。
