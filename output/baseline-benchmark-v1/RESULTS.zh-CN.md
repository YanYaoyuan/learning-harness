# ALFWorld 基线开发实验：实测结果

日期：2026-11-10。Qwen3-4B-Instruct-2507；双卡 5090。本轮为重复使用的开发集、单个环境/采样种子，不能作为正式测试或论文主结论。

## 完整 40 任务

| 方法 | 首次成功 | 预算内累计成功 | 平均调用 | 平均输入 token | 平均输出 token |
|---|---:|---:|---:|---:|---:|
| Direct JSON | 2/40 (5.0%) | 8/40 (20.0%) | 136.0 | 106446 | 1561 |
| Act（相同示例、去掉思考） | 26/40 (65.0%) | 27/40 (67.5%) | 57.2 | 97704 | 714 |

| Reflexion | 33/40 (82.5%) | 35/40 (87.5%) | 31.1 | 65725 | 556 |

最多 3 次尝试，每次最多 50 回合，总计不超过 150 次模型调用。反思计入预算；成功即停止。同调用/输出预算上限不代表实际 token 消耗相同。

## 配对效果与能说明的范围

- ReAct − Act，首次成功率差：+15.0 pp；任务组配对 bootstrap 95% CI [+0.0, +30.0] pp。
- ReAct − Act，累计成功率差：+15.0 pp；任务组配对 bootstrap 95% CI [+0.0, +30.0] pp。
- Reflexion − ReAct retry，首次成功率差：+2.5 pp；任务组配对 bootstrap 95% CI [+0.0, +7.5] pp。
- Reflexion − ReAct retry，累计成功率差：+5.0 pp；任务组配对 bootstrap 95% CI [+0.0, +12.5] pp。

ReAct 与 Reflexion 的 40 个首请求具有相同 prompt 和 request seed；其中 35 个原始输出完全相同。反思在首次失败之后才发生，首次差异不应归因于反思机制。

本轮可以校准旧执行基线，并区分示例/思考/同任务重试的候选收益。它没有更新模型参数，因此不能证明学习速度、参数内化、跨任务持续学习或 RSI。只看旧 action-only 基线不足以证明对成熟 agent harness 的优势；但这也不自动推翻旧实验内部的收集和特定任务迁移比较。
